# design-assets

Arte-fonte que **não** é servida ao público (fica fora de `public/` para não entrar no build/PWA).

- `bernardo-sprites/topdown/` — sprites top-down, ainda não integrados.
- `bernardo-sprites/reference/` — imagens de referência.

Para usar um asset no jogo, copie somente o necessário para `public/assets/`.
